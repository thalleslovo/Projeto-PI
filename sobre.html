Sobre o ConectaServ

Esta página Web é o Projeto Interdisciplinar (PI) do 1º Semestre do curso de Desenvolvimento de Software Multiplataforma da Fatec Franca - "Dr. Thomaz Novelino".

O objetivo do PI é elaborar um produto de software próximo à realidade profissional, desenvolvendo competências das disciplinas de Engenharia de Software I, Desenvolvimento Web I e Design Digital.

A ideia do ConectaServ é facilitar a conexão entre clientes que precisam de serviços e profissionais qualificados, de forma rápida, segura e transparente.
